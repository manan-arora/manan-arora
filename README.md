## ⭐ Featured Projects

### Unsaid - AI-Assisted Anonymous Messaging Platform

A modern anonymous messaging platform where users get a public inbox link to receive anonymous messages with AI-assisted message suggestions.

#### Features
- 🔐 Auth.js Authentication
- 📧 OTP Email Verification
- 📨 Anonymous Messaging
- 🔗 Public Profile Links
- 🤖 Gemini AI Message Suggestions
- 🎛 Inbox Toggle (Accept / Pause Messages)
- 🎨 Custom Neo-Brutalist UI

**Tech Stack:**  
Next.js • TypeScript • MongoDB • Mongoose • Tailwind CSS • Auth.js • Gemini API

**🔗 Live Demo:**  
https://try-unsaid.vercel.app

**🔗 Repository:**  
https://github.com/manan-arora/unsaid-anonymous-messaging
